챙김이 개인정보처리방침

시행일: 2026년 11월 11일 · 앱: 챙김이 (com.gyoche.check)

한 줄 요약

챙김이는 회원가입이 없고, 내가 넣은 정보를 서버로 보내거나 모으지 않아요. 등록한 물건·사진·기록은 모두 내 휴대폰 안에만 저장돼요. 광고와 사용 분석 도구도 넣지 않았어요.

1. 저장하는 정보와 저장 위치

  • 사용자가 직접 넣은 물건 이름, 날짜, 교체 주기, 메모, 금액, 자동차 주행거리, D-day 같은 기록
  • 사용자가 찍거나 고른 사진(물건·옷·영수증 사진)
  • 앱 설정(켠 탭, 알림 시간, 화면 모드 등)

이 정보는 휴대폰 안의 앱 저장 공간에만 저장돼요. 개발자는 이 정보를 볼 수 없어요. 앱을 지우면 함께 지워져요.

2. 인터넷을 쓰는 경우 (보내는 정보)

그 밖에는 인터넷에 연결하지 않아요.

3. 휴대폰 기능 사용

  • 카메라: 영수증·날짜·물건 사진을 찍을 때 휴대폰의 카메라 앱을 열어요. 앱이 카메라 권한을 직접 갖지 않아요.
  • 글자·바코드 인식: 휴대폰 안(Google Play 서비스의 ML Kit)에서 처리하고, 사진을 서버로 보내지 않아요. 다만 Google의 ML Kit는 기능 개선과 오류 진단을 위해 기기 정보(제조사·모델·OS 버전 등)와 성능 정보를 Google에 암호화해서 보낼 수 있어요. 사진·글자·기록 내용은 포함되지 않아요.
  • 말로 등록: 휴대폰의 음성 인식 기능(예: Google 음성 입력)을 불러 써요. 음성 처리는 그 기능을 제공하는 회사의 방침을 따라요.
  • 알림: 교체·유통기한 알림을 보내려고 알림 권한을 물어봐요. 휴대폰을 다시 켰을 때 알림 예약을 이어 가려고 부팅 완료 신호를 받아요.

4. 백업과 가족 공유

사용자가 직접 누를 때만 동작해요. 백업 파일은 사용자가 고른 곳(내 파일, 드라이브 등)에만 저장되고, 가족 공유 글은 사용자가 고른 앱(문자, 카카오톡 등)으로만 보내져요. 원하면 비밀번호로 잠글 수 있어요(AES-256 암호화). 비밀번호는 어디에도 저장하지 않아요.

5. 제3자 제공·판매

개인정보를 다른 회사나 사람에게 팔거나 넘기지 않아요.

6. 아이 정보

이 앱은 어른(보호자)이 쓰는 생활 관리 앱이에요. 아이 옷 사이즈 기록 기능도 보호자가 직접 넣는 기록이고 휴대폰 밖으로 나가지 않아요.

7. 정보 지우기

앱 안에서 기록을 지우거나, 휴대폰 설정 → 앱 → 챙김이 → 저장공간 → 데이터 삭제, 또는 앱을 지우면 모든 정보가 지워져요.
